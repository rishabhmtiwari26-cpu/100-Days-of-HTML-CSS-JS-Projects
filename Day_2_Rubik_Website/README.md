# Day 2 - Rubik's Cube | 100 Days of HTML CSS JS Projects

An interactive 3D Rubik's Cube with scramble generator and speedcube timer.

### Features
- 3D CSS Cube with drag to rotate
- Random Scramble Generator (WCA Format)
- Speedcubing Timer with Start/Stop/Reset
- Shuffle Animation

### Tech Stack
- HTML5
- CSS3 (3D Transforms, Preserve-3D, Perspective)
- Vanilla JavaScript

### How to Run
1. Clone the repo
2. Open `Day_2_Rubiks_Cube/index.html` in browser

### What I Learned Day 2
- `transform-style: preserve-3d` and `perspective`
- Mouse drag events for 3D rotation
- Timer logic with `setInterval`
- Scramble algorithm
